# Update Makefile for Bun Build and Test Targets

## Purpose and scope

Replace npm/npx/jest usage in `Makefile` with bun equivalents without changing the build output. Only `Makefile` (and `.gitignore` if required). Tests are already ported (task 002).

## Requirements

1. **Path discovery.** Replace both `$(shell npm explore @sdlcforge/packjs -- pwd)` with `$(CURDIR)/node_modules/@sdlcforge/packjs` (hoisted bun layout confirmed in task 001). Define it once (e.g. `PACKJS_PKG`) and derive `BABEL_PKG` and `ROLLUP_CONFIG` from it.
2. **Rollup / jsdoc2md.** `npx rollup` -> `bunx rollup` (or `node_modules/.bin/rollup`); `npx jsdoc2md` -> `bunx jsdoc2md`. Rollup and the CLI shebang remain Node (`JS_OUT_PREAMBLE='#!/usr/bin/env -S node --enable-source-maps'` is unchanged). Keep a single variable (`ROLLUP`, `JSDOC2MD`) per tool.
3. **Test target.** Delete `JEST`, `JEST_CONFIG`, `NODE_OPTIONS=--experimental-vm-modules`, `SRJ_CWD_REL_PACKAGE_DIR`, and the `cp -r ./coverage/*` step. New recipe runs `bun test --coverage --coverage-reporter=text --coverage-reporter=lcov --coverage-dir=$(COVERAGE_REPORTS) $(TEST)` (from the repo root; `bunfig.toml` scopes to `./src`), teeing to `$(TEST_REPORT)` and touching `$(TEST_PASS_MARKER)` exactly as before, including the `set -e; set -o pipefail` wrapper and the git rev header. `bun test` writes coverage progress to stderr, so keep `2>&1`. Keep `$(TEST)` as the optional filter. Preserve the multi-target `&:` grouped rule and its prerequisites (`package.json`, source files, `$(FANDL_EXEC)`); add `bun.lock` and `bunfig.toml` as prerequisites.
4. Leave `lint`, `lint-fix`, and build rules working; they invoke `dist/fandl-exec.js` under Node via its shebang - this is intentional and keeps lint exercising the Node path.
5. Do not alter incremental-build behavior: marker files drive test staleness; `.PHONY` changes are optional and must not make `make test` rerun when nothing changed.
6. **Build equivalence.** Run `bun install --frozen-lockfile`, `make build`; compare `dist/` with the pre-migration build at `/Users/zane/playground/sdlcforge/format-and-lint/dist` (`diff -r`). Expect no content differences other than ones attributable to the dependency tree; explain any difference. Confirm `README.md` regenerated by `make build` matches the committed one (`git diff --stat README.md` empty) - if jsdoc2md under bun differs, investigate before accepting.
